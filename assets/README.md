# Plugin icon

`tensor-plugin.png` is the Tensor plugin icon: the Tensor logo, a heavy condensed
TENSOR wordmark in deep red over a distressed, fractured surface, centered on a
black field.

The artwork is the project logo supplied by the maintainers, fitted to the
1024x1024 tile plugin icons require. Both plugin manifests reference this shared
asset; only the PNG is included in the npm package.
